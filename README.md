# Coffee Shop Sales Analysis

## Project Overview

This project analyzes coffee shop sales data using MySQL and Power BI
to understand sales performance, order trends, product performance,
store performance, and daily/hourly sales patterns.

The project includes SQL-based business analysis and an interactive
Power BI dashboard.

## Tools & Technologies

- MySQL
- SQL
- Power Bi

## Business Requirements

The analysis focuses on:

- Total Sales
- Total Orders
- Total Quantity Sold
- Month-over-Month Sales Growth
- Month-over-Month Order Growth
- Month-over-Month Quantity Growth
- Daily Sales Analysis
- Weekday vs Weekend Sales
- Store Location Performance
- Product Category Performance
- Top 10 Products
- Sales by Day and Hour

## SQL Analysis

SQL was used for:

- Data preparation and cleaning
- Date and time conversion
- Aggregations using SUM and COUNT
- GROUP BY analysis
- CASE statements
- Date functions
- LAG() for MoM analysis
- Subqueries
- Window functions
- Filtering and sorting

## Power BI Dashboard

The final dashboard provides an interactive view of:

- Sales KPIs
- Orders
- Quantity Sold
- Sales trends
- Product performance
- Store performance
- Day and hour analysis
